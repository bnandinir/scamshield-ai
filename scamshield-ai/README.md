# ScamShield AI

ScamShield AI is a simple AI-powered scam message detection system developed using Python and Flask.

## Features
- Detects suspicious scam messages
- Provides warning alerts
- User-friendly web interface
- Risk level indication

## Technologies Used
- Python
- Flask
- HTML
- CSS
- NLP Concepts

## Project Structure
scamshield-ai/
│
├── app.py
├── requirements.txt
├── templates/
├── static/

## How to Run

1. Create virtual environment
2. Activate environment
3. Install Flask
4. Run app.py

Command:
python app.py
